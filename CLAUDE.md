# ProPhoto instructions

Spec-driven development with OpenSpec is mandatory for Claude and every subagent it starts: no repository edit before an OpenSpec change exists, and delegated edits carry the change ID. Follow [AGENTS.md](AGENTS.md) for OpenSpec and [ARCHITECTURE.md](ARCHITECTURE.md) for implementation. Read the applicable scoped instructions. Claude uses `/openspec-propose` for a proposal and `/openspec-apply-change` for a prepared change. See the [contributor guide](docs/openspec/README.md) for the pinned CLI.
