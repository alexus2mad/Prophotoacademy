Відкрити редактор

Навичка редактора ProPhoto

Доручайте Codex або Claude Code редагувати сторінки Академії. Агент працює у візуальному редакторі й зберігає чернетку для вашого перегляду.

Встановлення

Потрібен Node.js версії 22 або новішої з npm. Вставте команду в термінал, щоб встановити навичку для Codex і Claude Code.

{{INSTALL_COMMAND}}
Завантажити ZIP
Встановити лише для одного агента

Додайте наприкінці команди --target codex для Codex або --target claude для Claude Code.

Як почати роботу

Відкрийте новий чат агента та під’єднайте браузер. Увійдіть у редактор як адміністратор Академії. Почніть запит із $prophoto-editor у Codex або /prophoto-editor у Claude Code та опишіть потрібну зміну.
