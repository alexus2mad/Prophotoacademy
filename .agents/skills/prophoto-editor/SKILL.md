# ProPhoto Academy page editor

Use the agent's browser tool to operate **Сторінки сайту** under the manager's own Academy administrator session. This skill also works outside the source repository.

## Open the right page

- Use the environment the manager named. For an unspecified destination, work in the [staging editor](https://staging.prophotoacademy.com.ua/admin/content) and save a draft. A design reference or a link supplied as an example does not select the publication destination. The [production editor](https://prophotoacademy.com.ua/admin/content) manages a separate set of pages.
- If a browser is unavailable, ask the manager to connect a browser the agent can operate. At the Academy login screen, let the manager complete sign-in. A read-only editor or a denied admin route is a blocker for writes. Keep authentication in the browser and use the editor's controls for all changes.
- For an existing page, use **Пошук сторінок**. Match its public path as well as its title. The team shares one draft per page. Preserve work already in the tab. If a draft exists, compare the relevant fields with the public page, when available, and keep other contributors’ edits. A request to *review* means inspect and report. A request to *preview an edit* means make the change and save the draft.
- For a new page, first search for its proposed path. Choose **Створити сторінку**, enter **Назва сторінки**, select the catalog section and template, and verify **Адреса сторінки** before **Створити чернетку**. The address uses a lowercase Latin slug with hyphens. The course and workshop templates also set the catalog section. **Практичний інтенсив** provides a photographic cover, expandable program, gallery, format and ticket card. Use the templates available on the target.

## Make the requested changes

| Brief | Editor action |
| --- | --- |
| Rewrite copy or adjust typography | Activate the text in **Попередній перегляд** or choose its section in **Структура сторінки** and edit the labeled field. For a specific visual change, open **Оформлення тексту** and use its available font, size, weight, color or alignment. Escape cancels the current inline edit. |
| Insert a paragraph, cards, carousel or other block | Use the **+** at the intended boundary inside the preview iframe. Match the surrounding headings. The toolbar’s **Додати блок** inserts after the selected custom block, or at the end when a native section is selected. Check the placement shown in the block library before choosing the block. |
| Move a block or edit one item | Click the authored block's **Перемістити** control, choose **Нове місце на сторінці**, and apply it, or drag the handle. Native sections act as placement landmarks. For a card, slide, topic or photo, select that item inside its block. Use the item-level controls to change its position. |
| Replace a photograph | Open the image field or click the photograph. Search **Бібліотека зображень** or use **Завантажити файл**, select the intended asset, then **Вставити зображення**. Supply an accurate image description and retain attribution. Uploaded marketing images have public URLs even while the page is a draft. Use approved public-facing material. |
| Work on a ticketed intensive | Add one topic per disclosure and one bullet per line. The program field supports `**emphasis**`. For a requested ticket change, choose the configured **Квиток для оплати** on **Перший екран**. Its offer supplies the payable price. If the brief quotes another price or the offer is missing, keep the existing binding and save the other edits in draft. Report the quoted and configured terms so the manager can resolve them before publication. |

Use the manager's supplied text, photographs and commercial facts. Keep unrelated fields intact. If the deployed editor cannot express a requested element, identify the missing control and its impact. Only apply a substitute layout if it fits the brief.

## Save, review and publish

1. Select **Зберегти чернетку** and wait for **Чернетку збережено**. If a response is interrupted, inspect the current status and reopen the saved version once it is safe to leave. Check whether the operation succeeded before retrying a creation, insertion or upload.
2. If another administrator changed the revision, retain the intended edits before choosing **Відкрити актуальну версію**. Compare the affected fields, reapply compatible edits and resolve overlapping changes with the manager.
3. Reopen the saved page. Check the changed text, image, links or block order at **Комп’ютер** and **Телефон**. Use **Структура й поля** when the narrow editor hides the inspector. Purchase controls in the editor preview are inert. Templates can save with unfinished blocks. Before publishing, check the template’s required fields, including photo descriptions. Fill missing material from the approved brief or return the draft with the specific items still needed.
4. A request to create, edit or prepare a page ordinarily ends with a saved draft. Use **Опублікувати** when the manager has requested publication to that environment. Publication releases the **whole saved draft**. If it includes unrelated unpublished edits outside the brief, identify them and resolve the scope first. When publication succeeds, open the ordinary public URL on the same host and verify the requested change. A checkout test creates an order and needs its own authorization.
5. Return the environment, page title, actual **saved draft** or **published** state, and a link. For a draft, copy the editor address with its `?page=` parameter. For a publication, link to the public page. Mention any outstanding material or visual discrepancy the manager needs to review.
