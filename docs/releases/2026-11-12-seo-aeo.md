# Academy SEO, discovery and legacy URLs — 12 November 2026

## Scope

This release improves Ukrainian search discovery for prospective students in Kyiv
and online throughout Ukraine. The findings, source references, migration
inventory and measurement limits are in [the SEO/AEO audit](../SEO_AEO_AUDIT_2026.md).
Implementation was completed with GPT 6.1 Sol.

The owner confirmed the Academy address as Київ, вул. Саксаганського, 24/25.
Metadata and the shared organization identity use that address. Older search
snippets mentioning Введенська, 32 are historical evidence, not current facts.

Page-specific metadata, truthful organization/course structured data and clearer
internal links make the existing pages easier to understand and discover. The
approved visual design and lesson/account interfaces are preserved. No invented
availability, prices, ratings, opening hours, event venues or business claims
are introduced.

`/courses` and `/page-in-progress` now return direct 301 redirects to `/academy`.
Course-category links retain `#courses`; repeated campaign parameters survive
before the fragment. The retained legacy presentation also uses Academy as its
canonical index, avoiding a cached redirect loop if that variant is used later.
This supersedes the temporary-redirect decision in the earlier navigation release.
The separate food-photography and commercial-content URLs remain distinct.

Production is explicitly indexable. Staging, synthetic reviews and private or
draft surfaces remain noindex; staging advertises no public sitemap entries.
Search and user-request crawlers receive complete metadata in the initial head.
This does not change authentication, paid-media authorization or training policy.

## Search Console setup

The verified domain property `sc-domain:prophotoacademy.com.ua` was inspected in
the in-app browser. Settings say it was added to the account on 11 November.
Google reported no manual actions or security issues. AI Search inclusion was
already set to Allow and was left unchanged. No permissions, associations,
analytics accounts, domain-move requests or removal requests were changed.

After both releases were verified, the canonical production sitemap
`https://prophotoacademy.com.ua/sitemap.xml` was submitted. Google immediately
reported **Success, 16 discovered pages, zero videos**. Only the production
sitemap was submitted. Screenshots are `.data/seo-2026/gsc/sitemap-success.jpg`
and `.data/seo-2026/gsc/sitemap-success-details.jpg`.

Individual URL inspection confirmed that the homepage was already indexed, with
Google selecting the inspected apex URL as canonical. Its stored crawl was from
5 November, so the absent user-declared canonical in that historical record
does not describe today's response. The live canonical is verified separately.
`/academy` was unknown to Google's index at inspection time. Google accepted one
indexing request for Academy and one recrawl request for the updated homepage,
adding both to its priority crawl queue. No duplicate requests were submitted.

The Performance and Page Indexing reports were still processing, with exports and
page/country filters unavailable. Sitemap discovery is not confirmation that
all 16 pages are indexed. Google's request to return in approximately one day
is a report-processing estimate, not an indexing guarantee.
The indexed-pages drilldown also had no populated URL examples, so the complete
historical inventory still cannot be reconciled against Search Console.

## Measurement limits

Five URLs were visibly observed in Google's public site search. That result is
not a complete inventory of indexed pages. Search Console access was restored
during release verification, but Google was still processing the Performance and
Page Indexing reports. The connected analytics account does not expose an
Academy property. The audit therefore makes no claim about traffic growth,
ranking gains or zero migration loss. The inspected legacy business URLs are
preserved; the versioned migration manifest can be extended when additional
evidence becomes available.

PageSpeed Insights returned HTTP 429 during the baseline. Search Console's mobile
and desktop Core Web Vitals reports both reported insufficient usage data for the
past 90 days. No field performance improvement is claimed. Google Business
Profile and Bing property work remains an access-dependent follow-up, with
concrete checks listed in the audit.
