# Adopt OpenSpec for Academy development

The Academy has multiple design variants, deployment modes and customer journeys. Its agent instructions and historical runbooks sometimes describe different versions of the same feature. Give each future change a written scope and verifiable scenarios, and establish an evidence-backed baseline at `0fee3bd99847`.

## What changes

- Install the pinned project workflow for Codex, Claude Code and GitHub Copilot.
- Inventory application pages, dynamic routes, integrations, jobs, editorial and operational workflows. Record evidenced behavior and unresolved discrepancies.
- Consolidate agent entry points and check coverage, spec validity and implementation-commit references locally and on GitHub.

## Capabilities

New capabilities: `spec-driven-development`, `public-navigation`, `public-programs`, `visual-interactions`, `search-discovery`, `hub-and-shop`, `public-content`, `checkout-and-fulfillment`, `identity-and-access`, `student-learning`, `curriculum-authoring`, `student-administration`, `notifications-and-integrations`, `content-management`, `review-and-sandbox`, `release-operations`, `media-production`.

## Impact

The implementation changes contributor tools, instructions and repository checks. It documents current product interfaces. It requires no migration, customer contact or deployment.
