# Visual content editing for the Academy

## Why

Changing a homepage photograph or workshop headline currently requires finding the right React component, fixture or CMS record. Editors need to recognize the page they are working on, preview a draft and publish it without a developer. The first editable publication must reproduce the current site.

## What Changes

- Add a Ukrainian page and section editor to the Academy admin, with image replacement, text alternatives, preview and explicit publishing.
- Supply the editor and existing public templates with the same identified editorial fields. Initialize them from current content, preserving the approved typography, order, crops, navigation and sales behavior.
- Support new course, workshop and general marketing landing content using established page structures. Keep unconfigured new products inquiry-led.
- Store page drafts and published documents in the public Sanity project, independently of the checkout catalog source. Keep local rehearsal and static review isolated.

## Capabilities

- New: `site-page-editing` covers page discovery, editing, media, safe preview and publication.
- Existing: `content-management` gains editor-managed public page content. The existing approved templates and purchase rules remain the rendering and commerce contracts.

## Impact

Admin workspace, public Academy marketing routes, page rendering and editorial media, public Sanity documents and environment settings, static review and acceptance tests.
