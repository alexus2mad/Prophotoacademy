## Why

Checkout replaces the sales page with a full page and offers a generic return to programs. Buyers need a visible close control that returns them to the offer they were viewing. Flash without fear also needs its upper prices and package selectors to lead to the detailed purchase cards.

## What Changes

- Use the existing Academy contact form and order summary in a single checkout dialog for eligible courses and workshop tickets.
- Give the dialog a visible close button and Escape dismissal. Keep the originating page in place when opening checkout there. Keep direct checkout URLs working and give them a relevant return destination.
- Link the Flash cover, introduction and mobile package selectors to the detailed ticket cards. Link each upper price to the corresponding lower card.

## Capabilities

### Modified Capabilities

- `checkout-and-fulfillment`: Shared modal checkout and dismissal for direct and in-page entry.
- `public-programs`: Correct single-page Flash ticket anchors and checkout entry.
- `site-page-editing`: Ticket announcement links and preview behavior.

## Impact

Academy checkout routes, the modal and header presentation, and authored workshop ticket navigation.
