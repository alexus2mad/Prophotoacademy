## Why

The current preview sends managers to a separate form when they select a photograph or heading. Managers need to see how a change looks in its actual position while they make it.

## What Changes

- Edit rendered copy in the preview and replace the selected image through the existing upload workflow.
- Use the same working page for the canvas and the field inspector. Keep explicit draft saving and publication.

## Capabilities

### Modified Capabilities

- `site-page-editing` adds in-place editing to the administrator's preview.

## Impact

Affects the admin page editor, preview bindings and editorial documentation. Existing page documents, public URLs, access rules, publishing roles and checkout remain compatible.
