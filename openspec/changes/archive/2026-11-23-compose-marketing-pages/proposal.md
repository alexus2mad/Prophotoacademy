## Why
Administrators can correct existing copy and photographs, but need a developer to compose a new arrangement, reuse an image or set a headline's appearance. They need these decisions in the Academy editor with an accurate preview.

## What Changes
- Add an ordered library of heading, paragraph, photograph, card grid and photo carousel blocks, including editable repeatable items.
- Offer independent page starters and a searchable marketing image picker with upload and reuse.
- Provide text appearance controls, with named choices that match the Academy design and a return to the original appearance.
- Preserve existing page content, managed enrollment components, explicit draft/publication and revision checks. Deliver to staging.

## Capabilities
### Modified Capabilities
- `site-page-editing`: build and preview marketing pages from blocks, presets and reusable assets.

## Impact
The page editor, public page templates, marketing asset endpoint, Sanity page payload, local sandbox and accessibility tests change. Existing pages require no data migration.
