## Why

Administrators need to rehearse real editorial work on staging. The current staging project also contains private lessons, so its project-wide Editor role grants access beyond public site content.

## What Changes

Connect staging's visual editor, public page reads and marketing image uploads to a separate staging Sanity project containing only public marketing content. Seed existing pages and verify a reversible text and photograph edit from draft through publication on staging.

### Modified Capabilities

The server-side content editor, existing staging startup guard, configuration examples and release procedure change. Production, course authoring, lesson assets, accounts and payments are outside the rollout.
