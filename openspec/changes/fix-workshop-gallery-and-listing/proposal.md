## Why

Dragging photographs on the new workshop page visibly interrupts browsing. The Academy homepage’s Workshops card leads to a list where the newly published workshop looks like an unrelated text link.

## What Changes

- Give a gallery gesture uninterrupted control of its rail. Keep ordinary clicks, touch swipes, arrow controls and the photo dialog usable.
- Present editor-published workshops alongside existing workshops using the same responsive row and details action.

## Capabilities

- `visual-interactions` — steady inline photo dragging.
- `public-programs` — consistent workshop discovery from the Academy homepage.

## Impact

Public gallery interactions and the workshop list on `/academy#workshops`. The existing staged workshop provides the acceptance case.
