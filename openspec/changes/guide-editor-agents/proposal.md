## Why

Managers and designers already have an authenticated Academy page editor. They need to give their coding agents the same editorial workflow in a portable form.

## What Changes

- Provide a project-discoverable and portable Agent Skill for creating and maintaining marketing pages through the visual editor.
- Explain setup, include Ukrainian example briefs and rehearse the workflow with disposable content.

## Capabilities

### Modified Capabilities

- `site-page-editing` gains agent-facing guidance for its existing user interface.

## Impact

Skill files, editorial documentation and specifications. The skill operates under the signed-in user's existing permissions.
