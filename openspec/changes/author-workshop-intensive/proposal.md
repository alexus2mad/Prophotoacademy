## Why

Build «Flash without fear» through the Academy’s visual editor to test whether a manager can reproduce the supplied workshop artifact. The owner requests a direct WayForPay ticket purchase in place of the application form.

## What Changes

Add a reusable practical workshop template with editorial sections and an explicit connection to a configured ticket. Create the actual workshop using the staging editor and verify responsive presentation and the purchase journey.

## Capabilities

### Modified Capabilities
- `site-page-editing`: add, edit, order, preview and publish intensive workshop sections and select a governed ticket.
- `public-programs`: show the published workshop once in the Academy workshop list and present its own photography, copy and purchase action.

## Impact

Page editor, published landing renderer and existing Academy checkout. Program data governs the ticket amount and payment fulfillment. The default workshop template remains available.
